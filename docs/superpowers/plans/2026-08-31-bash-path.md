# Bash PATH Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make Bash login, non-login, and reload paths deterministic, ordered, and free of duplicate entries without touching private secrets.

**Architecture:** `.profile` becomes the sole owner of static user paths and loads Cargo once. `.bash_profile` remains a minimal login dispatcher. `.bashrc` keeps interactive integrations, loads the private override, then performs the final stable deduplication and Nix ordering.

**Tech Stack:** Bash 5.3, POSIX profile files, `awk`, `tr`, `paste`, shell tests.

---

### Task 2: Centralize static PATH ownership

**Files:**
- Modify: `stow/bash/.profile`
- Modify: `stow/bash/.bash_profile`

- [x] **Step 1: Make `.profile` declare static user paths once.**

Keep the existing editor, Cargo, `PROJECTS_ROOT`, `PROFILE_LOADED`, and one
Juliaup PATH initialization. Add Bun and the static user directories after
Cargo/Juliaup in reverse prepend order so the resulting precedence is:

```text
$HOME/.local/bin
$HOME/bin
$HOME/.bun/bin
$HOME/.opencode/bin
$HOME/.local/share/composer/vendor/bin
<inherited PATH>
```

Only prepend optional directories that exist, except `$HOME/.local/bin`, which
retains its current unconditional user-tool precedence. Use a small local
helper that checks `:$PATH:` before prepending, then unset the helper before
returning from `.profile`.

- [x] **Step 2: Reduce `.bash_profile` to dispatch only.**

Keep only the guarded sources for `.profile` and `.bashrc`. Remove its Bun,
Juliaup PATH/completion, and `.local/bin` blocks; interactive Juliaup
completion remains owned by `.bashrc` so non-login interactive shells retain
it too.

### Task 3: Move final normalization to the end of `.bashrc`

**Files:**
- Modify: `stow/bash/.bashrc`

- [x] **Step 1: Remove duplicate static PATH mutations.**

Delete the early PATH deduplication block, the `move_to_end` block, the
Composer/OpenCode prepends, and the final duplicate Juliaup PATH/local-bin
blocks. Keep their functional integrations and Juliaup completion source.

- [x] **Step 2: Add final stable normalization after private overrides.**

After `.bashrc_local` and all remaining PATH-changing integrations, run the
existing stable `awk` deduplicator, then move the two Nix profile paths to the
end using the existing stable helper. Reassert the five contracted static
paths at the front after deduplication so a private override such as
`$HOME/bin:$PATH` cannot change their precedence. Do not print or inspect the
content of `.bashrc_local`; only source it as the existing private escape hatch.
